# Design System & Visual Language

## Design Philosophy

The application should have a modern, premium, minimalist aesthetic inspired by:

* Material 3
* Linear
* Notion Mobile
* Arc Browser
* Modern productivity applications

The UI should feel clean, focused, elegant, and distraction-free.

Avoid:

* Skeuomorphic designs
* Excessive gradients
* Excessive shadows
* Glossy effects
* Cluttered layouts

The app should look like a professional productivity tool rather than a utility application.

# Typography

Font Family:

* Inter
* Google Sans
* Roboto Flex

Preferred:

Inter

Typography Scale:

Display Large: 32sp

Headline: 24sp

Title: 20sp

Body: 16sp

Caption: 13sp

Use medium and semi-bold weights instead of heavy bold fonts.

---

# Shapes

Corner Radius:

Small: 12dp

Medium: 16dp

Large: 24dp

Cards and containers should have rounded corners.

Avoid sharp edges.

---

# Elevation

Use subtle elevation.

Cards:

1dp to 3dp

Floating Action Buttons:

4dp to 6dp

Avoid heavy shadows.

---

# Recorder Screen Design

## Idle State

Large circular record button centered on screen.

Button color:

#EF233C

Button size:

96dp - 120dp

Below button:

"Tap to Start Recording"

Use generous spacing and whitespace.

---

## Recording State

Large pulsing red indicator.

Live timer prominently displayed.

Examples:

00:05

05:23

01:12:45

Background remains calm and uncluttered.

Recording status should be immediately obvious.

---

# Recordings List Design

Each recording displayed as a modern card.

Card contains:

* Recording name
* Duration
* Date
* File size

Actions appear as icon buttons.

Use swipe-to-delete.

Use smooth animations for item removal.

---

# Animations

Use subtle animations throughout.

Examples:

* Record button scale animation
* Pulsing recording indicator
* Smooth screen transitions
* Animated list updates

Animation duration:

200ms - 350ms

Animations should feel responsive and professional.

---

# Empty States

When no recordings exist:

Display a simple illustration or waveform graphic.

Text:

"No recordings yet"

Subtext:

"Your recordings will appear here"

---

# Overall Experience

The application should feel:

* Professional
* Calm
* Minimal
* Modern
* Premium
* Fast
* Focused

The user should be able to understand and operate the app immediately without any learning curve.
